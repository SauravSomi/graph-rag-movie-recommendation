# GraphRAG Movie Recommendation System

An AI-powered movie recommendation system built using JavaScript, LangChain.js, Google Gemini, Neo4j, and Pinecone. It combines graph-based relationships and vector search to retrieve relevant movie information and generate context-aware recommendations.

## Tech Stack
- Node.js
- LangChain.js
- Google Gemini
- Neo4j Graph Database
- Pinecone Vector Database
- JavaScript (ES Modules)

## Features
- Graph-based movie relationship retrieval
- Semantic vector search
- LLM-powered responses using Gemini
- Document indexing and querying
- Retrieval-Augmented Generation (RAG)
